# 🖥 Desktop-сборка (Windows .exe)

Однофайловый исполняемый `FamilyTree.exe` для запуска на компьютере без
установленного Python: двойной клик → сервер стартует локально → открывается
браузер с приложением.

## Сборка

Требуется Windows + Python (любой 3.9+, используется только для сборки):

```bat
pip install -r requirements.txt pyinstaller
pyinstaller family_tree.spec
```

Готовый файл: `dist/FamilyTree.exe` (~40–60 МБ).

## Что делает exe при запуске

1. Рабочая папка — рядом с exe: там создаются `family_tree.db`, `media/`,
   `logs/` и `.env` (если их нет, `.env` генерируется со случайными
   VIEW/EDIT-токенами).
2. Поднимается uvicorn на `127.0.0.1:8123` (только локально, наружу не видно).
3. Открывается браузер по ссылке с VIEW-токеном.
4. EDIT-ссылка печатается в консоль и сохраняется в `.env`.

Закрыть — закрыть окно консоли (Ctrl+C).

## Важно

- Токены в `.env` рядом с exe: **не выкладывайте папку с .env куда-либо**.
- Первый запуск может занять несколько секунд (распаковка).
- Антивирусы иногда ругаются на PyInstaller-файлы — это ложное срабатывание,
  при необходимости соберите exe сами из этого исходника.
- Для семейного доступа с телефонов exe не подходит — нужен сервер (см.
  [ADMIN_GUIDE.md](ADMIN_GUIDE.md)).
